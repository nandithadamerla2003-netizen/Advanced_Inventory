About the Project

The Advanced Inventory & Supplier Management System is a web-based application designed to manage products, suppliers, inventory, purchases, sales and reports in one centralized system.

The backend is developed using FastAPI and MySQL, while the frontend uses HTML, CSS and JavaScript.

JWT Authentication is used to secure protected operations.

Technology Stack

FastAPI | MySQL | HTML | CSS | JavaScript | JWT | Kafka | Docker | GitHub Actions
